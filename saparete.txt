# ই-কমার্স স্ট্যান্ডঅ্যালোন প্রজেক্ট সেপারেশন প্ল্যান

Tech Baria প্রজেক্ট থেকে ই-কমার্স অংশকে আলাদা একটি স্ট্যান্ডঅ্যালোন প্রোডাক্ট হিসেবে বের করা — যাতে ক্লায়েন্টদের শুধু ই-কমার্স সল্যুশন দেওয়া যায়, POS ছাড়া।

### উভয় অ্যাপেই (storefront + dashboard) যা শেয়ার্ড:
- **Prisma schema** (1052 lines, 40+ models)
- **Server services** — প্রায় identical copies: `catalogService`, `salesService`, `customerLedgerService` ইত্যাদি
- **Features** — উভয় অ্যাপে ২২+ feature modules (pos, sales, customers, inventory, reports ইত্যাদি)
- **UI components** (`packages/ui`)

## Open Questions

> [!IMPORTANT]
> ### ১. ডাটাবেস স্ট্র্যাটেজি
> **অপশন A — Shared Schema (Recommended):**
> - একই Prisma schema রাখবো, কিন্তু e-commerce প্রজেক্টে POS-specific models গুলো থাকলেও ব্যবহার হবে না
> - সুবিধা: দ্রুত migration, কম breaking change
> - অসুবিধা: Schema-তে অব্যবহৃত models থাকবে
> 
> **অপশন B — Forked/Trimmed Schema:**
> - POS-specific models বাদ দিয়ে একটি lean schema তৈরি হবে
> - সুবিধা: পরিষ্কার schema, ছোট migration files
> - অসুবিধা: ২টি schema মেইনটেইন করতে হবে, future sync কঠিন

> [!IMPORTANT]
> ### ২. অ্যাডমিন প্যানেল
> ই-কমার্স-ওনলি প্রজেক্টে অ্যাডমিন প্যানেল কেমন হবে?
> - **অপশন A**: শুধু product management + order management + basic reports (simplified)
> - **অপশন B**: Full admin panel minus POS features (closer to current dashboard)

> [!IMPORTANT]
> ### ৩. Courier Automation
> আপনি কুরিয়ার বুকিং অটোমেশন উল্লেখ করেছেন। কোন কোন কুরিয়ার সার্ভিস ইন্টিগ্রেশন চান?
> - Pathao Courier
> - Steadfast Courier
> - RedX
> - Paperfly
> - eCourier
> - অন্য কোন সার্ভিস?

> [!IMPORTANT]
> ### ৪. নতুন প্রজেক্ট কোথায় রাখবেন?
> - **অপশন A**: এই monorepo-তেই নতুন app (`apps/ecommerce`)
> - **অপশন B**: সম্পূর্ণ আলাদা GitHub repo (Recommended — যেহেতু ক্লায়েন্টদের দেবেন)

## Proposed Changes

### Phase 1: নতুন প্রজেক্ট তৈরি ও ফাউন্ডেশন

#### [NEW] New repository / project setup
- নতুন Next.js প্রজেক্ট তৈরি
- Prisma schema migrate (e-commerce-only models)
- Auth setup (next-auth)
- Base UI components copy
- Tailwind + design system setup

#### ই-কমার্স-ওনলি Prisma Models:
```
✅ রাখবো:
- User, Account, Session, VerificationToken (Auth)
- Shop (Tenancy)
- Category, Brand, ProductType, Model, Series, Color, Storage, Ram
- Product, ProductImage, ProductVariant
- Sale (STOREFRONT channel only), SaleItem, SaleTender
- Customer (simplified - no due/credit system)
- ProductReview, HeroSlide, SiteConfig
- AuditLog, Notification
- Warehouse, WarehouseStock (simplified - single warehouse)

❌ বাদ দেবো:
- CashShift (POS-only)
- HeldSale (POS-only)
- Purchase, PurchaseItem, PurchaseTender (POS purchasing)
- Supplier, SupplierTransaction, SupplierPayment
- SerialNumber (IMEI tracking)
- InventoryLot (FIFO valuation)
- StockAdjustment
- Transfer, TransferItem (warehouse transfers)
- WarrantyClaim
- FinancialAccount, AccountTransfer
- Expense
- RestockOrder, RestockItem
- CustomerTransaction (due/credit ledger)
```
